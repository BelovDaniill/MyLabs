# Отчет по лабораторной работе №5

## Работа с DOM-деревом и событиями в JavaScript

## 1. Цель работы

Ознакомление с основами взаимодействия JavaScript с объектной моделью документа (DOM), обработкой событий и модульной структурой кода на примере приложения для учета финансов.

## 2. Структура проекта

Проект реализован с использованием модульного подхода:

* `index.html` - главная страница приложения.
* `style.css` - стилизация интерфейса, включая цветовую индикацию доходов и расходов.
* `src/index.js` - точка входа, инициализация слушателей событий и управление логикой формы.
* `src/transactions.js` - бизнес-логика: работа с массивом данных, расчет баланса.
* `src/ui.js` - манипуляции с DOM: отрисовка строк таблицы, обновление баланса, управление модальным блоком деталей.
* `src/utils.js` - утилиты для генерации ID, форматирования дат и обрезки текста.

## 3. Реализованный функционал

### 3.1. Учет транзакций

* **Добавление:** Через форму с валидацией (проверка на пустые поля и корректность суммы).
* **Отображение:** Динамическое добавление строк в таблицу.
* **Цветовая индикация:** Доходы (положительные суммы) подсвечиваются зеленым, расходы - красным.
* **Краткое описание:** В таблице выводится не более 4-х слов из описания транзакции.

### 3.2. Интерактивность

* **Делегирование событий:** Обработка кликов по кнопке «Удалить» и по строкам таблицы реализована через одного слушателя на элементе `<table>`.
* **Удаление:** Синхронное удаление данных из массива и соответствующих узлов DOM.
* **Детальный просмотр:** При клике на строку под таблицей открывается блок с полной информацией о транзакции (включая полный текст описания).

### 3.3. Расчеты

* Автоматический пересчет общего баланса при любых изменениях (добавление/удаление).
* Динамическое изменение цвета текста баланса (зеленый при `> 0`, красный при `< 0`).

## 4. Документирование кода

Весь код снабжен комментариями в стандарте **JSDoc**. Пример:

```javascript
/**
 * Вычисляет общую сумму всех транзакций в массиве
 * @returns {number} Общий баланс
 */
export function calculateTotal() {
    return transactions.reduce((sum, current) => sum + current.amount, 0);
}

```

## 5. Ответы на контрольные вопросы

### 1. Каким образом можно получить доступ к элементу на веб-странице с помощью JavaScript?

Для доступа к элементам используются методы объекта `document`:

* `getElementById(id)` - поиск по уникальному идентификатору.
* `querySelector(selector)` - поиск первого элемента по CSS-селектору.
* `querySelectorAll(selector)` - поиск всех подходящих элементов (возвращает NodeList).
* `getElementsByClassName` / `getElementsByTagName` - поиск по классу или тегу.

### 2. Что такое делегирование событий и как оно используется?

**Делегирование событий** - это прием, при котором один обработчик назначается на родительский элемент вместо того, чтобы назначать обработчики на каждый дочерний элемент.

**Применение:** В данной работе слушатель установлен на `table`. Внутри мы проверяем `event.target`, чтобы понять, нажата ли кнопка удаления или сама строка. Это позволяет корректно обрабатывать новые строки, добавленные в таблицу после загрузки страницы.

### 3. Как можно изменить содержимое элемента DOM после его выборки?

* `textContent` - заменяет только текстовое содержимое (безопасно).
* `innerHTML` - позволяет вставлять HTML-разметку.
* `value` - используется для изменения значений в полях ввода (`input`, `select`, `textarea`).

### 4. Как можно добавить новый элемент в DOM дерево?

1. **Создание:** `const div = document.createElement('div');`
2. **Наполнение:** `div.textContent = 'Привет!';`
