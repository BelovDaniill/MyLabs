# NoteKeeper

Учебное веб-приложение для создания заметок четырёх типов: общие, места, персонажи и события.

## Технологии
- PHP 8.1+
- SQLite
- PDO
- HTML, CSS, JavaScript
- Bootstrap 5.3

## Запуск
1. Установите PHP 8.1+ с расширениями `pdo_sqlite` и `mbstring`.
2. Откройте терминал в корне проекта.
3. Запустите встроенный сервер:

   ```bash
   php -S localhost:8000 -t public public/index.php
   ```

4. Откройте http://localhost:8000

При первом запуске база создаётся автоматически из `database/schema.sql`.

## Первый вход администратора
- Email: `admin@example.com`
- Пароль: `Admin123!`

Сразу после входа рекомендуется создать нового администратора с собственным email и сменить/удалить демонстрационную учётную запись. Не используйте эти учётные данные на публичном сервере.

## Возможности
- Регистрация и вход.
- Хеширование паролей через `password_hash`.
- Сессии, CSRF-токены и разграничение ролей.
- CRUD заметок и отдельные поля для мест, персонажей и событий.
- Поиск по тексту, типу и дате создания.
- Публичные заметки и статистика на главной.
- Панель администратора для управления пользователями и заметками.

## Важные замечания
- Для публикации на хостинге настройте HTTPS, безопасные cookie сессии и запретите прямой доступ к каталогу `database`.
- Встроенный PHP-сервер предназначен только для разработки.
- Восстановление пароля по email в базовую версию не включено.
- Перед сдачей проверьте все сценарии и подготовьте собственные скриншоты работы.

## Структура
- `app/Controllers` — обработчики запросов.
- `app/Models` — работа с данными.
- `app/Views` — HTML-шаблоны.
- `app/Core` — инфраструктура, авторизация, маршрутизация, валидация.
- `database/schema.sql` — схема SQLite.
- `public` — публичная точка входа и статические файлы.
